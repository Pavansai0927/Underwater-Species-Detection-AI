🌊 Underwater-Species-Detection-AI

Intelligent Marine Species Classification using Deep Learning, Computer Vision, and Transfer Learning.

🚀 Project Overview

This project builds an AI-powered Underwater Species Detection System capable of identifying marine organisms from underwater images using Deep Learning models.

The goal is to accurately classify underwater species for marine biodiversity monitoring, ocean research, and intelligent aquatic ecosystem analysis.

The system classifies multiple marine species with high accuracy using Custom CNN and Transfer Learning architectures.
